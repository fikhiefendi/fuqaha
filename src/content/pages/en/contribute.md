## Reporting an error

If an entry has a wrong date, name, place or reading, please fill in the [correction form](https://github.com/fikhiefendi/fuqaha/issues/new?template=duzeltme.yml). It asks for three things:

1. A link to the page,
2. What is wrong,
3. The correction and, if possible, its source (book, volume, page).

Since the biographies rely only on the text of al-Fawa’id, details that differ in other sources are not errors as such. You are still welcome to note them; they will be considered when further sources are added.

## Suggesting a record for the bibliography

If you know of a thesis, article, book or edition that is missing, please use the [suggestion form](https://github.com/fikhiefendi/fuqaha/issues/new?template=kayit-onerisi.yml). Pasting a BibTeX or RIS export from Zotero speeds things up.

## About the forms

The forms open on GitHub and need a free GitHub account. Every report is listed publicly, so you can follow when it is dealt with. All reports can be seen [here](https://github.com/fikhiefendi/fuqaha/issues).

## Using the data

The jurist and bibliography data can be downloaded as JSON, CSV, BibTeX and RIS from the [Licence and open data](../license/) page. If you build something with it, we would be glad to hear.
